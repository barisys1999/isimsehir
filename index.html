🔧 Firebase Kurulumu

Oyun gerçek zamanlı çalışmak için Firebase Firestore kullanır.
Aşağıya kendi Firebase config'ini yapıştır, ardından Kaydet'e tıkla.

  1. console.firebase.google.com adresine git
  2. Yeni proje oluştur → Build → Firestore Database → Test modunda başlat
  3. ⚙️ Proje Ayarları → Genel → Web uygulaması ekle (</>)
  4. Çıkan firebaseConfig objesini kopyala ve aşağıya yapıştır

Config tarayıcının localStorage'ına kaydedilir, sadece bu cihazda geçerlidir.
